আমাদের লক্ষ্য: একটি মানবিক, শিক্ষিত, সচেতন ও সমৃদ্ধ সমাজ গঠন। আমাদের কার্যক্রম: শিক্ষা সহায়তা, স্বাস্থ্যসেবা, মানবিক সহায়তা, পরিবেশ সংরক্ষণ, মাদকবিরোধী প্রচার ও সাংস্কৃতিক কার্যক্রম। আমাদের অঙ্গীকার: সততা, মানবিকতা, স্বচ্ছতা ও স্বেচ্ছাসেবার মাধ্যমে সমাজের উন্নয়ন। আমাদের মূলমন্ত্র: আমরা হলে সচেতন, সমাজের হবে উন্নয়ন।
